# Spiral Galaxy · Three.js

60,000 glowing particles, no shaders, ~70 lines.

**Live demo:** https://ankit-alpha-q.github.io/threejs-spiral-galaxy/

Built step by step on the MahaDev YouTube channel. Everything is in [`galaxy.js`](./galaxy.js).

## Run it
Any static server works, for example:
```
npx serve .
```

## Make it yours
- Change ARMS to 2 or 7
- Swap the core and edge colors
- Try r ** 3 for a brighter core
